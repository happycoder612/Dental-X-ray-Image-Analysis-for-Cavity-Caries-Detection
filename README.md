# Dental X-ray Image Analysis for Cavity Detection

This project analyzes dental X-ray images and identifies potential cavity regions using traditional image processing techniques. The system applies preprocessing, contrast enhancement, thresholding, segmentation, and morphological operations to highlight suspicious regions in dental radiographs.

## Features
- Dental X-ray preprocessing
- Noise reduction
- Contrast enhancement
- Tooth region segmentation
- Cavity candidate detection
- Visualization of detected regions

## Technologies
- Python
- OpenCV
- NumPy
- Scikit-Image
- Matplotlib

## Workflow

Input X-ray
→ Noise Reduction
→ Contrast Enhancement
→ Tooth Segmentation
→ Cavity Detection
→ Output Visualization
